# 和真バイトレーダー

徳島大学の学生が安全にアルバイト候補を整理するための、スマホ向けPWA試作版です。

## 内容
- ホーム、求人一覧、終了間近、お気に入り、プロフィール
- お気に入りは端末内に保存
- ライト／ダーク切替
- Service Workerによるオフライン表示
- iPhoneホーム画面追加用アイコン

## 注意
求人データはすべて架空の固定サンプルです。実在企業・実際の募集を示すものではありません。

## 公開方法（GitHub Pages例）
1. ZIPを展開し、中のファイル一式をGitHubリポジトリ直下へアップロード。
2. Settings → Pages → Deploy from a branch を選択。
3. main / root を選んで保存。
4. 発行されたHTTPS URLをiPhoneのSafariで開く。
5. 共有 → ホーム画面に追加。

PWA機能は file:// の直接プレビューではなく、HTTPS環境で確認してください。
